# Domain and Deployment

This portfolio is intentionally domain-neutral until the final public domain is connected. No `YOUR-DOMAIN.com` placeholder is published in the current build.

## Deploy

The site is static and can be hosted on Vercel, Netlify or GitHub Pages. The contact form opens a prepared WhatsApp message directly and does not require `/api/contact`.

## After connecting the real domain

Add the real production URL to canonical/social metadata in `index.html`. Then create a `sitemap.xml` containing the final public URL and add its sitemap URL to `robots.txt`.

## CV

No CV link or PDF is included in the current build. Add the final PDF later and then add a visible download link.

## Projects

The project showcase and case-study system are intentionally removed until real project material is ready.
